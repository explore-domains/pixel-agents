<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hook Payload Entry | Event arrives from external provider hook (untrusted transport) |
| Provider ID Extraction | Derived from URL path or event header (must match provider auth context) |
| Session Registry | Maps provider:sessionId pairs to agent IDs (in-process, trusted once normalized) |
| Persistence Layer | PersistedAgent includes providerId (file storage, trusted once written) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | Hook payload providerId | mitigate | Validate providerId matches auth context (shared secret, URL path) per D-13, D-14 before SessionRouter.register() |
| T-02-02 | Tampering | PersistedAgent.providerId | mitigate | Validate loaded providerId on restore; default to "claude" if missing (old data); no untrusted modification path |
| T-02-03 | Information Disclosure | Session registry state | accept | SessionRouter state is in-process only; no external exposure; same threat model as Phase 1 |
| T-02-04 | Denial of Service | Collision detection loop | mitigate | Collision detection runs once per agent spawn (constant time); hue shift calculation is O(1); no unbounded loops |

</threat_model>
