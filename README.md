# ED Pixel Agents

Pixel art office where your AI coding agents come to life as animated characters.

ED Pixel Agents turns AI coding sessions (Claude Code, Antigravity, Gemini CLI, OpenCode, and Copilot) into animated characters in a virtual office. Originally built for Claude Code as "Pixel Agents", ED Pixel Agents expands support to multiple concurrent agent families with updated branding and multi-agent lifecycle awareness.

## Features

- **Multi-Agent Support**: Track and visualize up to 5 concurrent agents from different providers.
- **Real-time Activity**: Agents respond instantly to CLI hooks (tool use, turn completion, permission requests).
- **Interactive Office**: Watch agents walk to their desks, type when active, and wander when done.
- **Customizable Layout**: Use the built-in editor to design your ideal AI office.
- **Teams & Sub-agents**: See how agents delegate work to teammates and sub-agents.

## Supported Providers

- Claude Code
- Antigravity
- Gemini CLI
- OpenCode
- GitHub Copilot

## Getting Started

1. Install the extension in VS Code.
2. Open the **ED Pixel Agents** panel.
3. Follow the intro tour to enable real-time detection for your favorite agent CLIs.
